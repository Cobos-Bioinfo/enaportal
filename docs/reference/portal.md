# Portal

Search, count, bulk retrieval, file reports and navigation, over the
[ENA Portal API](https://www.ebi.ac.uk/ena/portal/api/). The functions share
one `PortalClient`, created on first use; hold your own for repeated work.
The guides are [Searching the Portal](../guide/searching.md),
[Bulk retrieval](../guide/bulk.md) and
[Files and manifests](../guide/files.md).
